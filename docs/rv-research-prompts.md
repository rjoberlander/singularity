# RV Location Research Prompts
## Oberlander Family Trip Planning

Each prompt should return **10-15 DISTINCT DESTINATIONS** - unique places to visit, NOT multiple campground options at the same location.

**IMPORTANT:** For each destination, recommend ONE best camping option for our 30ft 5th wheel family. Don't list 5 campgrounds at Joshua Tree - just pick the best one and move on to the next destination.

## How to Use These Prompts

1. Copy the prompt for your target region
2. Open Claude with MCP database access
3. Claude queries database for full research instructions (with AllTrails requirements)
4. Claude researches and returns JSON with **10-15 distinct destinations**
5. Import the JSON via RV Locations page
